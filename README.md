# spese-pwa

App per il telefono che annota le spese in contanti (Cassa) e con la carta FLASH e le invia a un repo
privato di dati. Il codice non contiene dati: categorie, beneficiari e spese stanno nel repo privato,
il token GitHub solo nel telefono.

Pubblicata con GitHub Pages: https://migliosa.github.io/spese-pwa/

File: `index.html` (l'app), `sw.js` (cache per l'uso offline: cambiare `VERSIONE` a ogni rilascio),
`manifest.webmanifest` e icone (installazione sulla schermata home).
